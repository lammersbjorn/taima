# Security

Taima stores sensitive personal records, so security reports are very welcome.

**Please report vulnerabilities privately** through GitHub's [private vulnerability reporting](https://github.com/lammersbjorn/taima/security/advisories/new), not in a public issue. Include what you found, how to reproduce it, and which version you tested.

What counts:

- Data leaving the phone unexpectedly.
- Getting past the Face ID lock or discreet mode.
- Weaknesses in backup encryption.
- Crafted backups, CSV files or downloads that can harm the app or the data.
- Anything that exposes your records to other apps.

You'll get an answer within a week. Fixes ship in a new release, and reporters are credited unless they prefer otherwise.
