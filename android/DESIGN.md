# Taima Android

This trial extends Taima's established calm identity using Material 3. App screens use the Operate mode: collection and logging tasks lead; copy stays plain.

Use Material top app bars, navigation bar on compact widths and navigation rail at 600 dp, Android Back, a collection Add FAB, standard text fields, menus, dialogs and snackbars. Respect system insets, IME insets and font scaling. English and Dutch live in Android resources; content language follows the device.

Light surfaces are #F8FAF6 with #EEF1EB containers; green #1B7A47 is the primary action colour, with white labels. Dark surfaces are #141714 with #202420 containers and readable light green #85D5A4 primary controls. Other surfaces are neutral. Material's error role is reserved for validation. Body and title typography use the Material scale. Amounts use the platform monospace face for aligned numerals. Controls retain Material's minimum touch targets. Rows and dividers carry collection and session structure; avoid ornamental cards and rings.

Empty collection and stash states state what is missing and how to proceed. Database work and cryptography run off the main thread. Busy state disables destructive file actions and duplicate writes. Backup replacement requires a specific confirmation. Failed actions stay visible in a snackbar. No data or dates from a real collection belong in evidence.
